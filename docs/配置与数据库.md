# 配置与数据库说明

## 环境变量

复制 `.env.example` 为根目录 `.env`，启动时项目会自动加载。系统环境变量优先于 `.env`。

| 变量                    | 说明                                     |
|-------------------------|------------------------------------------|
| `DB_HOST`               | MySQL 主机地址                           |
| `DB_PORT`               | MySQL 端口，默认 `3306`                  |
| `DB_USER`               | MySQL 用户名                             |
| `DB_PASSWORD`           | MySQL 密码                               |
| `DB_NAME`               | 数据库名；使用 `sql/db.sql` 时应为 `xlt` |
| `JWT_SECRET_KEY`        | 足够长的随机 JWT 签名密钥                |
| `ES_HOST`               | Elasticsearch 主机地址                   |
| `ES_PORT`               | Elasticsearch 端口，默认 `9200`          |
| `CHAT_API_KEY`          | 聊天回答服务 API Key                     |
| `UTILITY_API_KEY`       | 问题重写、恶意检查和标题总结服务 API Key |
| `EMBEDDING_API_KEY`     | 向量化服务 API Key                       |
| `RERANK_API_KEY`        | 精排服务 API Key                         |
| `OSS_ACCESS_KEY_ID`     | OSS AccessKey ID                         |
| `OSS_ACCESS_KEY_SECRET` | OSS AccessKey Secret                     |

`.env` 已被 Git 忽略，不得提交真实凭证。模型名称、召回参数、文件限制、OSS Bucket 和 Endpoint 等配置位于 `config/` 下对应模块。

## AI 配置

聊天、辅助任务、向量化和精排服务地址分别由 `config/ai_config.py` 中的 `CHAT_BASE_URL`、`UTILITY_BASE_URL`、`EMBEDDING_BASE_URL` 和 `RERANK_BASE_URL` 配置。辅助模型默认为 `Qwen/Qwen3-8B`，模型名称和生成参数也在该文件中修改。

提示词正文位于 `config/prompts/`，包括：

- `system.md`：知识库问答
- `summary.md`：会话标题总结
- `malicious_check.md`：内容安全检查
- `rewrite.md`：结合历史对话重写问题

编辑模板时必须保留运行时占位符，例如 `{conversation}`、`{user_input}`、`{conversation_history}` 和 `{user_question}`。Elasticsearch 创建知识库索引使用 `ik_max_word` tokenizer，必须安装 IK 插件。

## 数据库初始化

空环境首次初始化：

```text
SOURCE sql/db.sql;
```

`sql/db.sql` 不是幂等迁移脚本，不能在已完成初始化的数据库上重复执行。已有数据库请先备份，再按顺序执行：

```text
SOURCE sql/migrations/001_add_role_knowledge_base_permission.sql;
SOURCE sql/migrations/002_constrain_session_name.sql;
```

需要清空并重建本地开发数据库时才执行：

```text
SOURCE sql/reset-dev.sql;
SOURCE sql/db.sql;
```

`sql/reset-dev.sql` 会删除整个 `xlt` 数据库，只能用于可丢弃全部数据的本地开发环境。
